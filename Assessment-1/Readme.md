CIT AI-Native Engineering Programme · Semester 1

| | |
|---|---|

## What you do

Write one AI task specification for each of five domains: Health, Transport, Education, Food and Scheduling. Each spec has five fields: Task, Input, Expected output, Constraints and two Edge cases. Then draw one flowchart in Excalidraw for a domain of your choice.

No code is needed for this assessment.

## Files in this folder

| File | What it is |
|---|---|
| `A1_Specification_Portfolio_Student_Package.pdf` | Instructions, marking rubric and the submission template |

## How to submit

1. Read the instructions and the marking rubric (pages 1–2).
2. Fill in the five specifications in the submission template.
3. Export your flowchart from excalidraw.com as PNG or SVG and add it on the flowchart page.
4. Go through the checklist, then upload everything as **one PDF** on the LMS.
